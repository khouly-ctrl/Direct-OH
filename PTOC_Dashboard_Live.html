Connect to Live Google Sheets

The dashboard is currently displaying sample data from April 2026. To switch to live data, publish your Google Sheets and update the URLs in the script.

1
Publish each source sheet to the web.
In Google Sheets: File → Share → Publish to web. For each sheet, choose the specific tab and select Comma-separated values (.csv). Click Publish and copy the URL.
2
Three sheets need to be published:
  • Targets sheet — daily visit targets
  • Actuals sheet — daily actuals with Date, Clinic, Follow-Up, IE, Hours per role
  • Schedule sheet — clinic operating hours per day of week
3
Edit this HTML file.
Find the SHEET_URLS object near the top of the script. Replace empty strings with your published CSV URLs. Save and reload.
4
Daily refresh.
As actuals are entered in Google Sheets, the dashboard reflects them on next page reload.

Privacy note: Published-to-web sheets are accessible to anyone with the link. PTOC operational data (visits, hours) is not PHI but is sensitive operational data. Confirm this access model is acceptable.

Methodology & Vocabulary
The terms used throughout the dashboard.

FU Unit: Follow-Up × 1 + Initial Examination × 2 + Consultation × 1.

FU Capacity (daily): (PT hrs × 2.5) + (PTA hrs × 2.0) + (Aide hrs × 0.5).

Utilization %: FU Units ÷ FU Capacity. For periods or multiple clinics: Σ FUs ÷ Σ Capacity (consolidated, never average).

Plan: Budgeted hours — reference capacity for the target visits, set before the day happens.

Normalized: Reference capacity for the actual visits delivered, computed after actuals come in.

Actual: Hours actually conducted by staff.

Variance: Actual − Normalized. Positive = used more hours than the volume required (overstaffed). Negative = under-staffed for the volume delivered.

Target %: Actual Visits ÷ Target Visits.
